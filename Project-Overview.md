# CGPA Calculator – Project Documentation

## 1. Project Overview
The CGPA Calculator is a web application designed to help university students calculate their academic results online, including both GPA (Grade Point Average) and CGPA (Cumulative Grade Point Average).
The first version of the application supports CGPA calculation for two semesters only. While it works perfectly within this scope, it is not yet flexible enough for universities that operate a three-semester academic system. Despite this limitation, the current version is stable, functional, and easy to use.

---

## 2. Target Audience
This project is built primarily for university students who struggle with calculating their GPA and CGPA manually. Many students find the process confusing, time-consuming, or inefficient, especially when relying on school manuals or unofficial guides.
The CGPA Calculator simplifies this process by providing a fast and accurate way to compute results.

---

## 3. How the Project Came to Life
The idea for the CGPA Calculator originated during our 100-level year in university. A friend once asked if I knew how to calculate GPA results. I suggested checking the school manual group for guidance.
After reviewing the guide, we attempted to calculate the results ourselves. However, the process was inefficient and took a significant amount of time. It became clear that many students likely faced the same frustration.
That experience inspired the idea of building a digital tool that could simplify GPA and CGPA calculations. From that moment, the CGPA Calculator project was conceived and eventually developed into a functional web application.

---

## 4. Areas for Improvement
Although the first version works effectively, there are several areas that need enhancement:

### a. Flexible CGPA Calculation
The current version limits CGPA calculation to two semesters. Future updates should allow users to calculate results across multiple semesters without restrictions, making the tool usable for all universities regardless of their academic structure.

### b. Improved GPA User Experience
The GPA section currently allows users to calculate results with only one course entered. This should be improved by setting a minimum number of required course inputs before calculation is allowed, ensuring more meaningful results and better user experience.

### c. User Interface and Branding
The current interface uses flashy and bright colors that do not align with the LAITECH brand identity, which focuses on cool and calm colors.
Additionally, accessibility should be considered. Some users may be color blind or sensitive to bright colors, which could negatively impact usability. The next version should adopt a cleaner, more brand-consistent, and accessibility-friendly design.

## Conclusion
The CGPA Calculator was created to solve a real student problem: inefficient and time-consuming GPA calculation. The first version successfully delivers a working solution, but improvements in flexibility, user experience, and design are necessary to make it more inclusive and scalable.
With its integration into Utility Toolbox, the CGPA Calculator is positioned to evolve into a more powerful and widely usable academic support tool.
